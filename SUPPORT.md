# Getting Support

| Type | Where |
|------|-------|
| Theme looks wrong / colours off | [Bug report](https://github.com/marvinrichter/gloam/issues/new?template=bug_report.yml) |
| Suggest a new theme or format | [Feature request](https://github.com/marvinrichter/gloam/issues/new?template=feature_request.yml) |
| Questions, setup help, discussion | [GitHub Discussions](https://github.com/marvinrichter/gloam/discussions) |
| Security concern | [SECURITY.md](./SECURITY.md) |

**Please do not use Issues for general questions.** Use Discussions instead — it keeps the issue tracker focused on actionable bugs and features, and your question may help someone else.
